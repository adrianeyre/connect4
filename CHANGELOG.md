## 1.0.0 (2026-09-07)

### ⚠ BREAKING CHANGES

* the build is Vite rather than react-scripts, the test
runner is Vitest rather than Jest+enzyme, and Node 26 is required.

react-scripts has been unmaintained since 2022 and does not run on Node
26, so "update all packages" could not be done in place — every
dependency the app had was pinned behind it. The toolchain is now the
same one as adrianeyre/multi-game-interpreter: Vite 8, Vitest 5,
TypeScript 6, ESLint 10 and Prettier 3.

Package changes:

- react/react-dom 18 -> 19, and `ReactDOM.render` -> `createRoot`. The
  IE11 polyfills went with it; React 19 does not support IE11.
- web-vitals 3 -> 6. v5 dropped FID for INP and renamed every getter to
  an `on*` subscriber, so reportWebVitals is rewritten rather than kept.
- node-sass -> sass. node-sass has been deprecated since 2020 and has no
  binary for a Node this new. The one `@import` between stylesheets is
  now `@use`, which Dart Sass 3 will require.
- enzyme is gone. It never shipped a React 17 adapter, let alone 19, so
  the four shallow-render snapshot tests are rewritten against Testing
  Library. They assert behaviour now instead of markup: that clicking a
  column reports it, that the turn passes to player 2, that starting a
  game lays out 42 cells. 19 tests, up from 6.
- The JSX transform is `react-jsx`, so the three components that only
  imported React for the classic transform now import just `FC`.
- tsconfig loses `suppressImplicitAnyIndexErrors` (removed in TS 5.5) and
  `baseUrl` (deprecated in TS 6); the one absolute import it served is
  now relative.

CI and release are the two workflows from multi-game-interpreter, with
the release trigger un-commented so a merged pull request releases, and
`main` changed to `master` to match this repository. The Pages deploy
needs Vite's `base` to be `/connect4/`, or every asset URL resolves
against the user site and 404s.

The version is set to 1.0.0 as the baseline semantic-release takes over
from.
